Tentang

Alhamdulillah, thanks be to the presence of Allah SWT. Sholawat and greetings may always be given to the Prophet Muhammad SAW.

{{APP_NAME}} is a project to present the holy book of the Quran in a lightweight and fast mobile web format, allowing even low-spec devices to access it without difficulty. The main features of {{APP_NAME}} adalah:

  • Fast and lightweight
  • Mobile web friendly
  • Last read marker
  • AI-based memorization tool
  • Dozens of language translation
  • Night and sepia mode for comfortable reading
  • Go to a specific verse within a surah
  • Each verse has its own URL and can be shared
  • Murottal audio for each verse (source: everyayah.com)
